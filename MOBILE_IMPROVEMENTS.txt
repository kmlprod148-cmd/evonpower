🚀 DÉPLOIEMENT
═══════════════════════════════════════════════════════════════

1. Les fichiers sont déjà intégrés au layout
2. Videz le cache Laravel :
   php artisan cache:clear
   php artisan view:clear

3. Compilez les assets (si nécessaire) :
   npm run build

4. Testez sur mobile :
   - Chrome DevTools (F12 → Device Toolbar)
   - Vrai smartphone iOS/Android

5. Visitez /mobile-demo pour voir la démo complète

🆘 SUPPORT RAPIDE
═══════════════════════════════════════════════════════════════

Problème : Contenu pas centré
Solution : Vérifier .evon-content { width: 100%; max-width: 100vw; }

Problème : Zoom iOS sur input
Solution : Font-size minimum 16px sur inputs

Problème : Bottom nav cache contenu
Solution : .evon-main { padding-bottom: 80px; }

Problème : Header disparaît
Solution : .evon-header { position: sticky; z-index: 1000; }
