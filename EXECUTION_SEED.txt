└───────────────────────────────────────────────────────────────┘

    Option 1 : Création simple (recommandé)
    ────────────────────────────────────────────────────────────
    php artisan seed:admin-users


    Option 2 : Réinitialisation complète (⚠️ DANGEREUX)
    ────────────────────────────────────────────────────────────
    php artisan seed:admin-users --fresh

    ⚠️ Cette option SUPPRIME tous les utilisateurs existants !


    Option 3 : En production
    ────────────────────────────────────────────────────────────
    php artisan seed:admin-users --force


    Option 4 : Reset complet en production (⚠️ TRÈS DANGEREUX)
    ────────────────────────────────────────────────────────────
    php artisan seed:admin-users --fresh --force
