🆘 DÉPANNAGE
═══════════════════════════════════════════════════════════════

PROBLÈME : Les graphiques ne s'affichent pas
SOLUTION :
1. Ouvrir la console (F12)
2. Vérifier que Chart.js est chargé
3. Tester avec dashboard-test.html
4. Vider le cache navigateur (Ctrl+F5)

PROBLÈME : Les données ne se mettent pas à jour
SOLUTION :
1. Vérifier la route /dashboard/realtime-data
2. Vérifier les logs Laravel
3. Tester l'endpoint directement
4. Vérifier la connexion réseau

PROBLÈME : Erreurs d'affichage
SOLUTION :
1. Vider le cache : php artisan cache:clear
2. Recompiler : npm run build
3. Vérifier les permissions
4. Tester en mode incognito
